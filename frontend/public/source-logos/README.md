# Accessibility source icons

Small publisher icons downloaded from the publishers' own sites for attribution links on Explore cards. The original asset URLs are recorded in `src/data/accessibilitySourceLogos.json` (relative to the frontend folder).

PNG files are size-limited copies of the supplied favicon or logo. The DMT SVG is the official header logo. No artwork was invented for sources without a retrievable icon; those badges use their publisher name instead. Icons identify the source of a report and do not claim endorsement or independent certification.
