This is local video stylization using OpenCV: edge-preserving smoothing,
warm colour adjustment, cel-shaded highlights and controlled contour lines.
It retains the original reveal motion, every source frame, 1280 × 720 size,
30 fps and 115-frame duration (3.833 seconds). The inspected source has no audio.
The WebM retains the source's dark background. The original project is untouched.
